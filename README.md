Supermarket Self-Checkout System (C Programming)

A  Supermarket Self-Checkout System developed in C.

Features

Product Display: Displays product codes, names, prices, and real-time available stock.

Cart Management:

Add items using product codes.

Remove items or decrease quantities 

View itemized cart contents and current totals.

Stock Validation: Automatically prevents users from adding more items than available in stock or entering invalid non-positive quantities.

Automated Billing & Discount Logic:

Automatically calculates total bill amount.

Applies a 10% discount for orders total equal to or exceeding 2,000 units.

Checkout & Cashier System:

sees cash payments to ensure sufficient funds.

Calculates and returns correct change.

Prints a complete final receipt.

Automatically deducts purchased items from inventory stock upon successful checkout.

Technical Specifications

Language: C

Libraries Used: Standard I/O (<stdio.h>)

Data Structures: Parallel arrays for product data, inventory, and cart tracking.

Architecture: Modular functional structure with menu-driven execution loops.
